# Product Image Prompts (copy-paste ready)

One prompt = one image. Paste a single block into ChatGPT (or any image model),
generate, save the file with the suggested filename, then move to the next block.

- Each prompt is fully standalone — no shared style block needed.
- Filenames follow the `incoming/images/` convention, ready for `npm run import-listings`.
- 2 prompts per product: `-1` is the main shot, `-2` is the hover/alternate shot.
- If a result comes out landscape, re-paste and add: "Portrait orientation, taller than wide."
